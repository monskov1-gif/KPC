# Стиль интерфейса

Правила от пользователя (21.10.2026) действуют для **всех** экранов игры.

## Общее настроение
- Мягкий, «облачный», светлый интерфейс приятных цветов. Ориентир — гардероб Infinity Nikki
  (кремово-розовый фон с арками, персонаж в центре на круглом подиуме, сетка вещей справа,
  золотая кнопка «Сохранить»). Интерфейс референса не копируем — берём настроение.
- Больше изображений, меньше надписей: иконки категорий, монеты, звёзды, кубки, вешалки и т. п.
  Текст — там, где без него непонятно (названия, описания, условия).

## Конкретные решения
| Что | Как |
|---|---|
| Редкость | Звёзды от 1 до 5 (common → legendary), без слов «Обычный/Редкий» |
| Характеристики вещи | Только по **долгому нажатию** на карточку (на ПК также правая кнопка мыши) |
| Тап по вещи | Надеть / снять (в черновик образа) |
| Условия испытания | ПК и планшеты (ширина ≥ 1000 px логических) — постоянно в левой части; телефон — по круглой золотой кнопке-кубку |
| Главные действия | Золотые «таблетки» (`UiTheme.primary`) |
| Второстепенные действия | Круглые кнопки с иконкой (`UiTheme.icon_button`) |
| Состояния | Не только цветом: значки ✓ / ✕ / ○, замок для несовместимых вещей |

## Палитра (`src/ui/ui_theme.gd`)
| Токен | Цвет | Назначение |
|---|---|---|
| BG_TOP → BG_BOTTOM | `#f8ede8` → `#ead6d4` | фон-градиент |
| PANEL | молочный, 78 % | панели-«облака» |
| TEXT / TEXT_DIM | `#6e5660` / `#a8929a` | текст (мягкий сливовый вместо чёрного) |
| GOLD / GOLD_LIGHT | `#d8b36e` / `#f0d9a4` | главные кнопки, выбранное |
| MINT | `#86cfc0` | цвет Кота, акценты |
| PINK | `#efb3c2` | шкалы характеристик, «новое» |
| OK / WARN / BAD | мягкие зелёный / янтарный / коралловый | статусы |

## Иконки
Рисуются кодом (`src/ui/icons.gd`): своя графика, без внешних лицензий. Силуэты одежды
по слотам служат и иконками категорий, и миниатюрами вещей — это PLACEHOLDER до появления
рендеров вещей. Новую иконку добавляем в `Icons.SHAPES` (полигон в квадрате 0..1) или в `Icons.draw`.

## Шрифт
Пока встроенный шрифт Godot. Округлый шрифт (например, Nunito, OFL) скачать из окружения не удалось
(CDN закрыт сетевой политикой) — см. `docs/OPEN_QUESTIONS.md`.

## Адаптивность
- Масштаб UI по короткой стороне экрана (`Game._update_ui_scale`), в портрете ×1.25.
- Элементы касания ≥ 44 px.
