# Версии на сайте

Каждая правка публикуется как новая версия (+0.01).

- **v0.03** (2026-10-21) — 3D-прототипы Кота, Габи и Соры (Blender): аниме-лица, волосы, уши, одежда по слотам, скелет и анимация покоя; тун-шейдер с контуром; вещи Соры по его референсу
- **v0.02** (2026-10-21) — Игровой интерфейс по UI-референсам: зал с арками, золотые рамки и картуши, медальоны категорий, карточки по редкости, шрифты Inter и Liberation Serif
- **v0.01** (2026-10-21) — Первая веб-версия: гардероб в мягком стиле, модное испытание, сохранения в браузере
