# Графика: как устроены модели и интерфейс

## 3D-прототипы персонажей
Строятся скриптом в Blender 5.2 (модуль `bpy`), без ручного моделирования:
```bash
python3 -m venv tools/bpyenv && tools/bpyenv/bin/pip install bpy   # один раз
python3 tools/art/gen_faces.py                                      # текстуры лиц
tools/bpyenv/bin/python tools/art/build_characters.py [kot gabi sora]
```
Результат — `art/characters/<id>.glb`: меш, скелет из 17 костей, анимация `idle`.

| Часть | Как сделано |
|---|---|
| Тело | Открытая базовая модель MakeHuman (CC0, `tools/art/basemesh/`, `tools/art/mh_body.py`): морф-цели (пол, подросток, худощавость, грудь), поза рук/ног через её скелет и веса, аниме-пропорции (длинные ноги и руки, стопы). Параметры — `CHARACTERS[id]["body"]["mh"]` |
| Голова и лицо | Вылепленная голова (`sculpt_head`): V-челюсть с углом, подбородок, скулы, виски, глазницы, надбровья, нос (спинка, кончик, крылья), губы, ямка под губой; плотная сетка. Кожа, нос, губы, румянец — текстура (`gen_faces.py`, фронтальная проекция) |
| Глаза | Глазные яблоки за прорезями век (радужка с волокнами, лимб, блики). У Кота ресницы, складка века и брови — объёмные (`build_lashes`): густая верхняя линия с «крылом», отдельные ресницы, нижние ресницы |
| Волосы | «Шапка» + пряди-ленты с градиентом цвета в вершинах (корни → кончики); пучки, хвост, хохолок |
| Уши | Кошачьи уши у Кота и Соры (по референсам 04 и 12) |
| Одежда | Меши-шаблоны `garment__<слот>__<шаблон>`; игра показывает нужные и красит в цвет вещи (`model_template` в `items.json`). Общие шаблоны — «оболочки» тела; образ Кота (свитер-фонарик с вышивкой, карго с ремешками и брелоком, ботинки на платформе, заколки-рыбки и облачко) — отдельные шаблоны по развороту `art/references/characters/16_kot_turnaround.jpg` |
| Бельё | `underwear__briefs` (мужчины), `underwear__bra` + `underwear__panties` (женщины). Полностью раздеть персонажа нельзя: бельё скрывается только под закрывающей его вещью (`CharacterModel.UNDERWEAR_COVERED_BY`) |
| Скелет | Свои кости; веса — две ближайшие кости по расстоянию (надёжнее автоматических весов на несвязных мешах) |

### Эталон Кота — Meshy-листы
`art/references/meshy/` — скриншоты сгенерированной модели (тело, образ со всех сторон, глина, сетка).

### Сверка с оригиналом наложением («1 в 1»)
Пользователь проверяет модели, накладывая арт на скриншот по линии челюсти. Это автоматизировано:
```bash
GODOT=<путь> tools/art/ref_overlay.sh portrait kot     # лицо и причёска (реф. 16, крупный портрет)
GODOT=<путь> tools/art/ref_overlay.sh front kot        # во весь рост спереди
```
- В модели есть ориентиры — пустые узлы `lm_*` (подбородок, глаз и его углы, повязка, нос, рот, контур щеки
  и челюсти, макушка, кончики ушей, края копны, ворот; для роста — ширина силуэта на уровнях, ремень, пол).
- Ориентиры оригинала сняты по сетке: `art/references/characters/16_kot_landmarks.json`.
- `tools/art/ref_overlay.py` совмещает арт с рендером по подбородку и глазу (масштаб по вертикали, без поворота)
  и печатает расхождение каждой точки в U (U — расстояние глаз–подбородок); картинка — 4 панели, включая 50/50.
- Параметры лица (глаза, нос, рот, челюсть, повязка) — `tools/art/face_params.json`, общий для текстуры и лепки.
- Критик `model-critic` (`.claude/agents/model-critic.md`) разбирает наложения и требует правок с цифрами.

В Godot модель грузит `CharacterModel` (`src/visual/character_model.gd`): аниме-шейдер
`art/shaders/toon.gdshader` (плоская светотень, контровой свет) + контур `outline.gdshader`.
Витрина для проверки — `scenes/dev/character_lineup.tscn`.

**Это прототипы, не финальная графика**: обувь упрощена, нет мимики (кроме нарисованного
лица), одежда — общие шаблоны. Финальные модели нужно делать художнику по тем же именам мешей и костей.

### Известные ограничения прототипа
- Свет в рендерере Compatibility (веб): всенаправленные лампы пересвечивают тун-шейдер — используем одну
  направленную лампу + встроенный rim.
- Вещи одного слота делят один шаблон меша (например, все обувь — `footwear__shoes`).

## Интерфейс
Графика интерфейса — `tools/art/gen_ui.py` → `art/ui/` (рамки, стекло, кнопки-картуши, медальоны, фоны).
Правила стиля — `docs/UI_STYLE.md`, эталоны — `art/references/ui/`.

## Шрифты
`art/fonts/` — Inter и Liberation Serif (OFL), см. `art/fonts/README.md`.
