# Каталог референсов

Референсы задают **направление**, а не требование копировать конкретную игру, модель, интерфейс или здание (ТЗ, §3, §8).
Источник всех файлов — пользователь (коммит «Референсы», 2026-10-21). Лицензия внешних изображений неизвестна:
использовать только как внутренний ориентир и не включать в сборку игры.

Папка исключена из импорта Godot (`.gdignore`).
