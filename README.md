# KPC — Kot's photo collection

Сюжетная 3D-RPG про Кота: исследование, отель, гардероб и модные испытания (Godot 4.4).

**Играть в браузере:** https://monskov1-gif.github.io/KPC/ — номер версии виден в углу экрана,
история версий — [docs/RELEASES.md](docs/RELEASES.md).

Сейчас доступен вертикальный срез гардероба: примерка, модное испытание с объяснением результата,
сохранения в браузере. Персонажи пока показаны заглушкой из примитивов.

## Структура
- `src/` — код (домен, интерфейс), `data/` — данные (одежда, испытания, тексты), `scenes/` — сцены
- `tests/` — автотесты, `tools/` — тесты, скриншоты, публикация
- `play/` — собранная веб-версия (публикуется на GitHub Pages)
- `docs/` — архитектура, стиль, открытые вопросы, исходные ТЗ; `art/references/` — референсы

Как собирать и тестировать — [docs/BUILD_AND_TEST.md](docs/BUILD_AND_TEST.md).
