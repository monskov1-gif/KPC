# Базовая модель тела — MakeHuman (CC0)

Тела персонажей KPC строятся на открытой базовой сетке MakeHuman, а не с нуля (`tools/art/mh_body.py`).

| Файл | Что это |
|---|---|
| `base.obj` | базовая сетка hm08 (тело ~13k граней, кисти с пальцами, стопы, группы суставов `joint-*`) |
| `targets/*.target` | морф-цели: пол, возраст (young/child), худощавость, пропорции, грудь |
| `default.mhskel`, `default_weights.mhw` | скелет и веса — поза рук и ног без надломов в плечах и запястьях |

Источник: https://github.com/makehumancommunity/makehuman (`makehuman/data/…`).
Лицензия ассетов — **CC0 1.0** (`LICENSE.ASSETS.md` рядом): можно использовать и менять без ограничений.

Голова базовой модели срезается — у персонажей своя аниме-голова (`build_head`).
