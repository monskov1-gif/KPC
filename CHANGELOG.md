# Журнал изменений

## 2026-10-21
### Добавлено
- Проект Godot 4.4: структура папок, автозагрузка `Game`, локализация `ru`.
- Референсы разложены по папкам с каталогом `art/references/README.md`; исходные ТЗ и сценарий — в `docs/source/`.
- Система одежды по ТЗ: каталог, общий гардероб, слоты и совместимость, комплекты, модное испытание
  с объяснением результата, советы, награды без дублей, крафт, магазин, версии сохранений.
- Экран гардероба в мягком «облачном» стиле: иконки вместо надписей, звёзды редкости, характеристики
  по долгому нажатию, условия испытания слева (ПК) или по кнопке-кубку (телефон).
- Инструменты: `tools/run_tests.sh` (64 автотеста), `tools/capture.sh` (скриншоты).
- Агенты-критики в `.claude/agents/`.

### Исправлено (по ревью критиков)
- Загрузка повреждённых сохранений и настоящих v0-файлов; потеря ресурсов при достижении лимита;
  накопление состояния при новой игре/загрузке; валидация наград испытаний; стабильная сортировка;
  вёрстка (перенос по буквам, обрезанные списки, высота окон).

## Известные проблемы
- Модели персонажей и одежды — заглушки.
- Свет на скриншотах проще реального: съёмка через программный OpenGL.
